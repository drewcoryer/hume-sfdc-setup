Connect Salesforce

For a Salesforce admin. The values go straight into the backend. Drew does not see them.

Before you fill this in

  1. Create an integration user (or pick an existing one) with API Enabled, Create and Edit on Lead and Task, and Read on Product2 and PricebookEntry.
  2. In Setup, create an External Client App (App Manager or External Client App Manager) or a Connected App.
  3. Turn on OAuth, add the scope Manage user data via APIs (api), and check Enable Client Credentials Flow. Any callback URL works, for example https://localhost/callback.
  4. In the app's policies, set Run As (Client Credentials Flow user) to the integration user.
  5. Copy the Consumer Key and Consumer Secret and paste them below. New apps can take up to 10 minutes before the login works.

Setup, then My Domain, then Current My Domain URL. Use the .my.salesforce.com address, not login.salesforce.com.

App Manager, open the app, then Manage Consumer Details (or Settings, then OAuth Settings, then Consumer Key and Secret).
